# Project Continuity Documentation Hub

**This is the first folder to read when starting a new AI chat, AG session, or Kiro session.**

---

## Purpose

This folder contains everything a new AI assistant needs to understand the Togs & Dogs / usmissionhero platform project without reading the entire repository history or relying on a single long chat session.

---

## Recommended Reading Order

1. **`current-state.md`** — What's deployed, what's blocked, what's next
2. **`guardrails.md`** — What must never be done without approval
3. **`agent-operating-model.md`** — How ChatGPT, Kiro, and AG work together
4. **`decision-log.md`** — Key architectural and business decisions made
5. **`release-timeline.md`** — Major milestones in order
6. **`document-map.md`** — Where to find detailed docs by topic
7. **`lessons-learned.md`** — Mistakes and patterns to avoid
8. **`master-handoff-prompt.md`** — Copy/paste prompt for starting a new ChatGPT session
9. **`continuity-maintenance-checklist.md`** — How to keep these docs accurate

---

## When to Use This

- Starting a new ChatGPT conversation about this project
- Onboarding a new AG/Kiro session after context was lost
- Resuming work after a long gap
- Handing off to a different AI model or assistant
- Reviewing project direction before making decisions
- **Rolling over to a fresh session** after a major milestone or when a conversation grows too large (see `continuity-maintenance-checklist.md` for the rollover process)

---

## Maintenance

Update these docs when:
- A major milestone is completed
- A key decision changes
- A new guardrail is established
- The project state significantly shifts

See **`continuity-maintenance-checklist.md`** for the full update protocol including release closeout steps and AI handoff procedures.

Keep documents concise. Link to detailed release notes rather than duplicating content.
